\section{Experimental setup}
\label{sec:setup}

The benchmark runs as one Flyte factory on an EKS cluster: a graph of cached tasks, each of which publishes a
versioned artifact (\cref{fig:factory}). The trees and rules fit on a CPU pod, each decision model and the RL model
train on one NVIDIA L4, and the zero-shot model runs as a shared vLLM service in the same cluster. Each of these is
itself a batch pod that someone had to size.

\begin{figure}[tbp]
\centering
\includegraphics[width=0.9\linewidth]{figures/diagrams/factory.pdf}
\caption{The benchmark as a Flyte factory. The three measured corpora are sources published by their own
factories; every box below them is a cached task whose output is a versioned artifact partitioned by release
(and by approach, for the per-approach boxes).}
\label{fig:factory}
\end{figure}

We trained k8s-2 three times on the same data (\code{rsk-k8s-2}, \code{-s2} and \code{-s3}). The seed controls
data order, LoRA initialization and RL sampling; GPU kernels are not bit-for-bit deterministic, so even the same
seed would not reproduce a model exactly. The zero-shot model is scored once. Tables show seed 1 with its
bootstrap interval unless they say otherwise, and the leaderboard adds the mean and range over the three seeds.
Seed 1 is the best or tied-best test seed for most trained approaches, so its numbers are slightly optimistic;
\cref{sec:res-seeds} reports all three. \Cref{app:runs} lists every cluster run.
